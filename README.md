# منصة الأفق — منصة رقمية متعددة الأقسام (Multi-Niche Platform)

منصة ويب عربية كاملة، مبنية لتبدأ بنيتش واحد (بأضعف منافسة وأكبر جمهور) ثم تتوسع لأي عدد من الأقسام/النيتشات **دون أي تعديل على الكود** — فقط من لوحة التحكم.

---

## ✨ الفكرة

بدل موقع بفكرة واحدة، هنا **البنية التقنية هي المنتج**:

- **قسم رئيسي** = نيتش كامل (مثال: التقويم والمواعيد).
- **أقسام فرعية** داخله = مقالات / أدلة / أدوات تفاعلية / أي شيء تضيفه.
- **المحتوى** يُنشر مرتباً تحت (قسم رئيسي ← قسم فرعي).
- **الصفحة الرئيسية** عامة: تعرض كل الأقسام الرئيسية + الفرعية + جزء من محتوى كل قسم.
- **نظام ربط داخلي قوي** يجعل أي صفحة مرتبطة بعدة صفحات أخرى (لا توجد صفحة يتيمة)، ويجذب الزائر للتعامل أكثر.
- **لوحة تحكم متكاملة**: إحصائيات تفصيلية، إدارة محتوى، إدارة أقسام، إدارة مستخدمين، وإعدادات الموقع والإعلانات.

> البداية المبنية حالياً: نيتش **«التقويم والمواعيد»** (🗓️) — مقصود لأنه من أسهل النيتشات تحقيق ترتيب في جوجل (كلمات سؤال طويلة + جمهور خليجي/عربي كبير + محتوى مرجعي متكرر الزيارة) مع **6 أدوات تفاعلية تعمل فعلياً** و**5 محتويات جاهزة** كنقطة انطلاق.

---

## 🧱 البنية التقنية

| الطبقة | التقنية | السبب |
|---|---|---|
| الواجهة + الـ API | **Next.js 14** (App Router, Server Components) | سرعة + SEO قوي (SSR, sitemap, metadata) + Actions |
| اللغة | **TypeScript** (strict) | أمان الأنواع في كل الطبقات |
| الـ ORM / قاعدة البيانات | طبقة بيانات مخصصة فوق **SQLite** (`node:sqlite` مدمج) | صفر إعدادات، ملف واحد، قابلة للاستبدال بـ Prisma/Postgres لاحقاً |
| الواجهة | **Tailwind CSS** + RTL كامل | تصميم عربي نظيف ومتجاوب |
| الرسوم البيانية | **Recharts** | مخططات الإحصائيات |
| المصادقة | Session عبر Cookie موقّع (HMAC) + bcryptjs | دخول آمن للوحة التحكم |
| التحليلات | **مدمج** (beacon → `/api/analytics`) + دعم GA4 وAdSense | تتبّع يومي/أسبوعي/شهري/سنوي + زيارات **كل صفحة ومقال على حدة** |

> 💡 ملاحظة عن قاعدة البيانات: البيئة الحالية تمنع تحميل محرك Prisma الخارجي، لذلك كُتبت طبقة بيانات خفيفة فوق SQLite المدمج في Node بنفس واجهة Prisma (`prisma.<model>.<method>`) — **للاستبدال بـ Prisma/Postgres لاحقاً لا تغيّر سوى ملف `src/lib/db.ts`**، فكل استدعاءات بقية الكود تستخدم نفس النمط.

## 📖 دليل الاستخدام (من لوحة التحكم)

### 1) إنشاء نيتش جديد (قسم رئيسي)
1. `الأقسام` ← نموذج «قسم رئيسي جديد (نيتش)» أعلى الصفحة.
2. املأ: الاسم، slug إنجليزي، أيقونة (emoji)، الترتيب، الوصف، ونشط.
3. احفظ → يظهر فوراً في الرئيسية والـ footer والـ sitemap.

### 2) إضافة أقسام فرعية إليه
- تحت كل قسم رئيسي ستجد نموذج «+ قسم فرعي جديد».
- أنشئ ما تحتاج: `مقالات` / `أدلة` / `أدوات تفاعلية` / أي قسم فرعي باسمك الخاص.

### 3) نشر محتوى (مقال / دليل / أداة / صفحة)
1. `المحتوى` ← «+ إضافة محتوى جديد».
2. اختر **النوع**، اكتب **العنوان** (زر «توليد من العنوان» يملأ الرابط تلقائياً).
3. اختر **القسم الرئيسي** ثم **القسم الفرعي**.
4. اكتب المحتوى (يدعم **Markdown**: عناوين، جداول، قوائم، و**روابط داخلية** مثل `/tools/hijri-gregorian-converter`).
5. املأ حقل **SEO** (عنوان + وصف يظهران في جوجل) والوسوم.
6. اختر `منشور` وحدد التاريخ → اضغط نشر.

- **الأدوات التفاعلية:** البرمجة جاهزة مسبقاً في `src/tools/registry.ts`. عند نشر أداة تختار «المفتاح» (مثل `hijri-gregorian`) فقط، والواجهة تُبنى تلقائياً.

### 4) الإحصائيات (التحليلات)
- `لوحة التحكم`: زيارات **اليوم / الأسبوع / الشهر / السنة**، الزوار الفريدون، منحنى آخر 30 يوم، أعلى الصفحات، توزيع الأجهزة والمتصفحات والأقسام.
- `التحليلات`: تبديل الفترات (7/30/90/365) + **جدول زيارات كل صفحة/مقال على حدة** مع نسبة الحصة.
- كل محتوى منشور له عدّاد زيارات يظهر في قوائم المحتوى وصفحة التعديل.

### 5) المستخدمون والإعدادات
- `المستخدمون`: إضافة/تعديل/تعطيل/حذف، وتغيير الأدوار (مسؤول/محرر) وكلمات المرور.
- `الإعدادات`: اسم الموقع والشعار النصي والوصف، روابط التواصل، **كود AdSense**، معرف **Google Analytics**، وتفعيل/تعطيل نظام التحليلات المدمج.

## 🕸️ كيف يعمل الربط الداخلي (ضمان عدم وجود صفحة يتيمة)

كل صفحة محتوى تُعرض فيها وحدات تلقائية مرتبة حسب علاقة الصفحة:
1. **مزيد من [القسم الفرعي]** — نفس القسم الفرعي.
2. **من قسم [القسم الرئيسي]** — أقسام فرعية أخرى داخل نفس النيتش.
3. **الأكثر زيارة في المنصة** — عبر الأقسام (أو «تصفح الأقسام» إن لم تتوفر زيارات بعد).
4. **أعلى/أسفل** (الصفحة السابقة والتالية داخل نفس القسم الفرعي).

إضافة إلى:
- **الـ footer** يدرج كل الأقسام الرئيسية + أقسامها الفرعية + أحدث المحتوى.
- **الرئيسية** تعرض كل القسم + جزء من محتوى كل قسم فرعي.
- **sitemap.xml + robots.txt** يولّدان تلقائياً لكل صفحة منشورة.

نتيجة: أي زائر يدخل لأي صفحة يجد مسارات متعددة نحو صفحات أخرى، وجوجل يزحف عبر الشبكة كاملة.

│  ├─ api/

│  │  └─ auth/login|logout
│  ├─ sitemap.ts  ·  robots.ts
├─ actions/              # Server Actions (نشر/تعديل/حذف محتوى، أقسام، مستخدمين، إعدادات)
├─ components/           # مكوّنات الموقع + الربط الداخلي
├─ tools/                # الأدوات التفاعلية + registry (أضف أدواتك هنا)
└─ lib/
   ├─ db.ts              # طبقة البيانات (استبدلها بـ Prisma/Postgres عند الحاجة)
   ├─ auth.ts  ·  settings.ts  ·  stats.ts  ·  track.ts  ·  utils.ts  ·  types.ts
prisma/schema.sql        # تعريف الجداول (SQLite)
scripts/seed.mts         # البيانات الأولية
scripts/test-orm.mts     # اختبار تكامل لطبقة البيانات (23 حالة)

## 🔧 إضافة أداة تفاعلية جديدة (مثال)

1. أنشئ مكوّناً في `src/tools/MyTool.tsx` (`'use client'`).
2. سجّلها في `src/tools/registry.ts`:
   ```ts
   'my-tool': { name: 'اسم الأداة', icon: '🧮', description: '...', Component: MyTool }
   ```
3. من لوحة التحكم: `المحتوى` ← إضافة جديد ← نوع `أداة` ← اختر مفتاح `my-tool` ← انشر.

## 📊 نماذج إحصائيات متوفرة

- زيارات اليوم / آخر 7 أيام / الشهر / السنة.
- الزوار الفريدون (30 يوم) حسب session.
- منحنى الزيارات اليومية.
- **زيارات كل URL/مقال/أداة/قسم فرعي/قسم رئيسي** بشكل منفصل + نسبة الحصة.
- توزيع: الأجهزة (جوال/حاسوب/لوحي) · المتصفحات · الأقسام.

---

## 🗺️ خارطة الطريق المقترحة (بعد الإطلاق)

- **إضافة نيتشات** بنفس المنطق (أقسام رئيسية جديدة) — دون لمس الكود.
- **صور ومعرض** ورفع مخصص (حالياً روابط خارجية فقط).
- **تصدير/نسخ احتياطي** لقاعدة البيانات.
- **نشر تلقائي** (RSS/قناة تليجرام) لكل مقال جديد.
- **تحسين SEO**: بيانات منظمة (JSON-LD: Article/BreadcrumbList) — الهيكل جاهز.
- **نسخة إنجليزية** أو تعدد لغات.

## ⚠️ ملاحظات النشر (Production)

- حوّل `metadataBase` في `src/app/layout.tsx` إلى نطاقك الفعلي (يُستخدم في Open Graph/sitemap).
- حدّث نطاق `sitemap.ts` و`robots.ts` أيضاً.
- ضع `SESSION_SECRET` قوياً في `.env` (لا تُحمّله في المستودع).
- استخدم نطاقاً + HTTPS.
